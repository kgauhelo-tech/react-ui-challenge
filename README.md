h1: ReactTS challenge

This is my first project using the React framework to develop a we page.

For this challenge, a list of UI designs for webpages was handed posted on github. Our task was to first close the GitHub repo to our devices and then choose 1 design from the provided list. Following that, we were to find the necessary resources to implement the chose design using react and its components.

After implementation, the next part of the assignment is to build the project and deploy it using any free hosting platform.
